## 1. 项目核心（宗旨）

> **人机协同 · 万物归元 · 皆可 Workflow**  
> **节点是死的，人是活的** — 流动的 Workflow，人可随时绕行、插队、场外办事再回来。  
> **只做 MVP，不做花里胡哨。**

这是本项目的**北极星**，实现与文档冲突时以本节为准（并回写 README 首页）。

### 1.0 归档与会话（已决 · 无争议）

| 规则 | 说明 |
|------|------|
| **归档 ≠ 新群聊** | 归档只释放本机进程与目录占用，**不**结束会话、**不**新建 Session、**不**新建群模板 |
| **再发仍在本会话** | 归档后再发消息 = 解档并继续**同一**会话 |
| **可无限归档** | 同一会话可反复归档 / 解档 |
| **续跑** | 往回/再跑=右侧「从这里继续」**线性追加克隆**；往前跳未完成步=**直达不克隆**；旧待确认标「已绕过」 |
| **新会话唯一入口** | 只有左栏主动「开聊」才新建会话 |

代码常量：`shared` → `SESSION_ARCHIVE_RULES`。

### 1.1 凝练表述

| 关键词 | 含义 |
|--------|------|
| **人机协同** | 工作流里人与机同台；闸门、输入、审核是一等公民 |
| **万物归元** | 脚本 / Agent = **元节点**；工作室与 Agent **解耦**，渐进接入 |
| **皆可 Workflow** | 节点是死的锚点，人是活的水流；可中途场外办事，再流回主线 |
| **简洁桥梁** | **聊天框 + 流程图** 即可，拒绝花哨堆砌 |

**产品形态一句话**：人机交互的聚合可视化平台——左会话、中对话与闸门、右流程（流动可见）。

### 1.2 执行纪律

| # | 纪律 |
|---|------|
| 1 | **只做 MVP**，不做花里胡哨 |
| 2 | 能力用「元节点 + 线性 workflow」表达，不先上重型编排器 |
| 3 | 本机优先，不夹带远程后台 |

### 1.3 边界

- 不做云端多租户；不替代 Cursor/Grok 本体  
- 不做复杂 BPMN / 断点精确续跑  
- MVP 不做 GUI 安装包（本机 Web）  
- 真实业务 Agent 按需后接（已有 echo + script + 熔炉）

## 2. MVP 范围与实现对照

### 2.1 定义

本机浏览器打开 → 配置成员/群 → 开聊 → 对话与闸门 → 右栏节点推进 → 归档（释资源）→ 可再发/解档仍在本会话 → 可「从这里继续」（前进跳或追加克隆）→ 可再归档。

### 2.5 验收清单

1. `npm run dev:server` + `npm run dev:web` 可打开工作台与设置（前端 **http://127.0.0.1:5173**）  
2. 能新建/克隆成员（echo 与 script 两种）、新建/克隆群模板（含闸门步骤）  
3. 开聊后左栏见会话，中栏见消息（BubbleList），右栏节点与当前高亮变化  
4. 人工提交与同意/拒绝闸门行为正确；script 有输出；**等人时界面标红突出**；闸门按钮在输入区右侧  
4b. 输入框 **Enter 发送**、Shift+Enter 换行；`/` `@` `#` 面板可用  
4c. 设置中「支持与交流」为浅灰其它区；文案为点赞支持口径  
5. 跑完可归档（或超时自动）；归档只省资源；再发仍在本会话；可克隆追加节点并再次归档  
6. 聊天可改名、可删除；刷新后数据仍在  
7. 设置 → 支持与交流 / 关于与更新可打开

## 3. 成员 / 群 / 工作文件夹（摘要）

### 成员类型

| 类型 | 说明 |
|------|------|
| `echo` | 示例回显 |
| `script` + `file` | 脚本/程序文件：bat/cmd、ps1、sh、py、js/mjs、ts(tsx)、rb、php、vbs、jar、exe… |
| `script` + `command` | 任意本机命令；占位 `{input}` `{folder}` `{sessionId}` |

脚本增强字段：`runtime`、`args`、`env`、`showScriptPopup`（或遗留 `showConsole`/`hideWindow`）、`useHumanAsStdin`、`successCodes`。

**执行原则**：一切以成员/命令配置为准；不包 ECW 壳、不擅自改 cwd。弹窗开则 Windows 直接 `Start-Process` 配置的脚本。

**弹窗优先级**：成员/快捷指令 `showScriptPopup` > 遗留字段 > 全局 `app-settings.showScriptPopup`（默认开）。

### cwd 优先级

`script.cwd`（显式）→ **脚本文件所在目录**（file 模式）→ `member.workFolder` → `session.primaryWorkFolder` → `group.workFolder` → `process.cwd`

### 发需求推断 + 终检暴露越界

产品要求见 [technical-design.md §2.0.3](./technical-design.md)；**实现后置**，MVP 可用 script + 人工闸门代替终检。

### 2.20 版本 2.0.1（2026-08-13 · **安全加固**）

- 本机 REST/WebSocket：回环 Origin + 随机 `ACW_API_TOKEN`（`/api/bootstrap` 发令牌；`/api/health` 免鉴权）。
- 停止/超时仅在真实退出码属于成功码时记 `ok`；注销会话清理 PID 与 PTY。

- WebSocket 断线重连；设置页可退出全屏；已知漏洞依赖升级。

- 流程轨折叠旧轨上未执行的废弃节点（含未绕过的归档待确认），不再把已执行节点收起来。
### 2.22 版本 2.2.0（2026-08-17 · **最终封板**）

- Windows 双击 `start.bat` 报「不是内部或外部命令」：批处理改纯 ASCII + CRLF（cmd.exe 按字节偏移定位下一行，多字节中文会截断后续行），中文提示移入 `start.mjs`；新增 `.gitattributes` 锁定换行。
- 常驻交互终端（`waitForExit: false` / `detach`）不再被判「执行超时」：PTY 启动成功即推进节点、不挂超时定时器，进程标记 detach 保留可输入，归档时统一回收。
- `demoRepair`：老库演示成员幂等补写 `waitForExit:false`（四重前置条件，不动用户自建配置）。
- 终端卡：宽 1080px、预览 40 行贴底、补 cwd、无输出收成一行；进程结束后禁止输入并提示。
- 成员设置「基础 / 高级」改标签页；去掉类型下拉；运行时默认 `cmd`；新建预填安装目录。
- 待确认取消顶部大卡片，说明并入输入框 placeholder，「同意」旁加 i 详情；会话列表显示相对时间。
- 移除右栏「资源」页及其前后端死代码；进程回收由归档与终端「停止」负责。
- 文档示例移除个人手机号 / 微信号。
