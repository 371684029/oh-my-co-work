## 0. 运行包一键启动（给最终用户）

1. 下载 [`packages/`](../packages/) 中与系统匹配的 zip（打包产物，**无需 npm install**）  
2. 解压 → 双击 `start.bat`（或 `./start.sh`）→ 自动开浏览器  
3. 关闭浏览器 **不会**停服务；**关闭启动窗口或 Ctrl+C** 即可结束服务  

开发者本地打运行包：`npm run pack`（写入 `packages/apple-co-work-v{N}-{平台}-{架构}.zip`；同大版本覆盖，新大版本会删掉旧大版本包）。

## 1. 启动（开发：两个终端）

```bash
cd apple-co-work
npm install

# 终端 1 — API（3780；空库会自动 seed「演示流」）
npm run dev:server

# 终端 2 — 前端（5173）
npm run dev:web
```

浏览器打开：**http://127.0.0.1:5173**  
（优先用 `127.0.0.1`，不要只用 `localhost`，避免 IPv6 连不上。）

健康检查（可选）：

```bash
curl http://127.0.0.1:3780/api/health
# 期望：ok=true，integrity.ok=true，version 含 1.0.0-dev
```

## 2. 确保能看到演示数据

空库首次启动会自动写入：

| 类型 | 名称 |
|------|------|
| 成员 | 示例回声、示例命令、统一管理员 |
| 群模板 | **演示流** |

若开聊下拉里**没有「演示流」**：

1. 顶栏进 **设置 → 设置（偏好）**  
2. 打开 **「显示演示示例」**  
3. 回到 **工作台** 刷新下拉  

仍没有：先停 server，删 `data/` 后重启（会重新 seed）：

```bash
# 停掉 npm run dev:server 后
rm -rf data          # Linux / macOS
# Windows: Remove-Item -Recurse -Force .\data
npm run dev:server
```

## 3. 推荐演示路径（约 2 分钟）

1. 顶栏点 **工作台**  
2. 上方开聊下拉选群模板 **「演示流」** → **开聊**  
3. 出现「确认开始」闸门 → 输入框可写项目参数（如 `我的项目 需求A`）→ 点右侧 **通过**  
4. **需要你输入**（项目信息步）→ 再提交一段参数（空格/换行会切成 `#1` `#2`…；**同会话内递增追加，不覆盖**）→ **提交**  
5. **示例回声**跑完 → 审核闸门 → 点 **同意**（可附言）  
6. **示例命令**跑完 → 再 **同意**  
7. 右侧 **流程** / **群报告** 看节点状态与 `#` 参数  
8. 全部完成后出现 **确认归档** → **同意归档**（或等超时自动归档，默认 3 小时）  
9. 归档后再发一条消息 → **仍在本会话（解档）**；续跑点「克隆并从此开始」追加节点

### 你会看到什么

| 区域 | 演示点 |
|------|--------|
| 左栏 | 会话列表（群模板 / 成员分区） |
| 中栏 | 气泡对话、闸门说明、输入区右侧大按钮 |
| 右栏 | 流程轨节点推进；群报告里的 `#` 参数与节点 I/O |

## 4. 常见卡点

| 现象 | 处理 |
|------|------|
| 页面打不开 | 确认两个进程都在；用 `127.0.0.1:5173` |
| 没有「演示流」 | 设置里打开「显示演示示例」；或删 `data/` 重建 |
| 会话显示「待恢复」 | **1.0 R02**：重启过 API 会中断未归档任务。点 **继续 / 归档 / 放弃** |
| 开聊报「工作目录被占用」 | **已撤 R04**：同目录允许多会话；若仍见旧闸门，点同意即可重试 |
| 成员步要 `#1` | **1.0 CI01**：按闸门提示提交项目参数后再跑 |
