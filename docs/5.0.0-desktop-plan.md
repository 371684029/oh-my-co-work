# 5.0.0 桌面原生客户端（Electron + TypeScript）实施计划

## 🎯 核心目标
将 **oh-my-co-work** 从当前的 Web + Node 本地服务形态正式演进为完整的 **5.0.0 Electron 跨平台桌面应用（macOS / Windows / Linux）**。
采用全栈 **TypeScript / JavaScript** 技术栈，彻底统一前端（Vue 3）、主进程（Electron Main Process / Node.js）与服务引擎（Node Server），避免接触 Rust 引入的学习与维护成本。

---

## 🏗️ 架构与技术选型

### 1. 桌面壳选型：Electron (TypeScript / Node.js)
- **核心选型**：Electron (Main / Preload / Renderer 三层架构)
- **优势**：
  - 100% 统一 TypeScript / JavaScript 技术栈，零 Rust 学习成本。
  - Node.js 环境与 Electron 主进程同源，天然直接加载原生模块（`node-pty`, `better-sqlite3`），无需编译复杂的 Sidecar 伴生可执行二进制。
  - 生态成熟，拥有极其丰富的托盘、快捷键、自动更新 (`electron-updater`) 社区库支持。

### 2. 进程与服务集成架构
- **Main Process (主进程)**：由 TypeScript 编写的 `electron/main.ts` 负责启动环境配置、主窗口生命周期、系统托盘 (Tray)、全局热键与本地端口分配。
- **In-Process Server / Node 引擎绑定**：直接在 Electron 主进程生命周期中 `import` 现有的 Node 服务（`server/src/index.js`），无缝共享同源 Node.js 运行时与 `better-sqlite3` 数据库句柄。
- **Preload Script (预加载桥接)**：通过 `electron/preload.ts` 安全地向渲染进程暴露统一的 Bridge API（`window.__ACW_DESKTOP_API__`），完美对接现有 `useDesktopBridge.js`。

## 🛠️ 5.0.0 核心功能拆解

### Phase 1：Electron 骨架建立与 Node 引擎内嵌 (5.0.0-alpha)
- [ ] **TS/Electron 项目配置**：创建 `electron/` 目录 (`main.ts`, `preload.ts`)，配置 `electron-builder` 与开发启动脚本 (`npm run dev:electron`, `npm run build:electron`)。
- [ ] **Node 引擎内嵌与生命周期**：主进程启动时自动初始化服务端监听，应用关闭时优雅清理全部衍生 PTY 与节点进程。
- [ ] **Bridge 状态自动接通**：Preload 脚本安全注入 `window.__ACW_DESKTOP_ENV__ = 'electron'` 和原生 API 句柄，连通 `useDesktopBridge.js`。

### Phase 2：原生系统托盘与窗口行为治理 (5.0.0-beta)
- [ ] **系统托盘 (System Tray)**：
  - 常驻系统托盘图标（macOS 顶栏 / Windows 右下角），右键菜单支持：「打开工作台」、「显示/隐藏桌宠」、「快捷启动 Workflow」、「检查更新」、「退出」。
- [ ] **窗口行为治理**：
  - 点 `X` 关闭窗口时默认隐藏至系统托盘而非退出应用，确保常驻 PTY 和 Workflow 后台持续运行。
  - 支持配置「开机自启」与「静默启动至托盘」。

### Phase 3：系统原生通知与全局快捷键 (5.0.0-rc)
- [ ] **原生通知推送**：
  - 使用 Electron 原生 `Notification` API，将节点审批请求、Grok 任务完成通知直接发送到系统通知中心。
  - 点击系统通知自动唤起并置顶主窗口，导航至对应 Workflow 会话。
- [ ] **全局快捷键 (Global Hotkeys)**：
  - 通过 Electron `globalShortcut` 绑定快捷键（如 `Option + Space` / `Alt + Space`），一键唤醒工作台或极简对话卡片。

### Phase 4：平滑自更新与打包发布流水线 (5.0.0 Release)
- [ ] **`electron-updater` 自动更新**：
  - 结合 `useDesktopBridge` 中的 `applyDesktopUpdate(manifest)`，实现后台自动检查新版本、静默下载更新包，并在用户同意后重启覆盖。
- [ ] **多平台构建打包 CI/CD**：
  - 配置 `electron-builder` 多平台打包：macOS (`.dmg` / `.zip`)、Windows (`.exe` 安装包 / 免安装绿化包)、Linux (`.AppImage` / `.deb`)。

## 🔐 安全与环境护栏
1. **Context Isolation (上下文隔离)**：启用 `contextIsolation: true` 并禁用渲染进程的 `nodeIntegration: false`，仅通过 `contextBridge` 暴露白名单 API，确保 Web 层安全。
2. **本地通信锁**：Electron 主窗口仅加载本地 Vite 构建产物或回环服务，拦截并拒绝加载非白名单的外部协议。
3. **数据库与快照安全**：打包升级时优先调用 `/api/backup` 触发 SQLite 完整性检查与本地自动备份。
