# 5.0.0 桌面原生客户端（Desktop App Shell）实施计划

## 🎯 核心目标
将 **oh-my-co-work** 从当前的 Web + Node 本地服务形态正式演进为完整的 **5.0.0 跨平台桌面应用（macOS / Windows / Linux）**。
做到：托盘常驻、窗口极速唤醒、独立桌宠/工具挂件、系统原生通知、全局快捷键拉起 Workflow，以及平滑静默自更新。

---

## 🏗️ 架构与技术选型

### 1. 桌面壳选型：Tauri (Rust + WebView)
- **推荐选型**：Tauri v2
- **优势**：产物极小（< 15MB，区别于 Electron 的 100MB+）、内存占用低、自带安全的 Rust 原生能力扩展与轻量系统托盘支持。
- **降级选型**：Electron (若 node-pty 原生 C++ 模块交叉编译受阻时作为备选)。

### 2. Sidecar 子进程架构
- 将现有的 Node.js 后台服务 (`server/src/index.js`) 及其原生依赖 (`node-pty`, `better-sqlite3`) 作为桌面壳的 **Sidecar 子进程** 随应用启动。
- 桌面壳在启动时自动找寻可用端口（默认 `3780`），启动 Sidecar 后把 WebView 指向本地服务地址，或通过本地回环 IPC 加速。
- 桌面壳关闭时，负责优雅退出并回收 Sidecar Node 进程及衍生 PTY 进程。

## 🛠️ 5.0.0 核心功能拆解

### Phase 1：原生壳初始化与 Sidecar 生命周期 (5.0.0-alpha)
- [ ] **项目骨架搭建**：创建 `src-tauri` / `src-electron` 目录，配置构建与开发脚本 (`npm run dev:desktop`, `npm run build:desktop`)。
- [ ] **Sidecar 进程管理**：Rust/Main 进程主导 Node 后台启动、健康检查 (`/api/health`)、端口守护与应用退出时的资源清理。
- [ ] ** Bridge 状态接通**：注入 `window.__ACW_DESKTOP_ENV__` 和 `window.__ACW_DESKTOP_API__`，接通 `useDesktopBridge.js`。

### Phase 2：原生系统托盘与窗口控制 (5.0.0-beta)
- [ ] **系统托盘 (System Tray)**：
  - 常驻系统托盘图标，提供右键菜单：「打开工作台」、「显示/隐藏桌宠」、「快捷启动 Workflow」、「检查更新」、「退出」。
- [ ] **窗口行为治理**：
  - 点击窗口关闭按钮 (`X`) 默认拦截并隐藏至系统托盘，避免误关 PTY 终端或工作流。
  - 支持应用启动时选择「静默启动至托盘」。

### Phase 3：系统原生通知与全局快捷键 (5.0.0-rc)
- [ ] **原生通知推送**：
  - 将节点闸门审核、Grok 执行完成、人工干预提醒直接转换为系统级 Native Notification。
  - 点击系统通知直接激活并置顶应用窗口，并导航至对应的会话。
- [ ] **全局快捷键 (Global Hotkeys)**：
  - 支持绑定全局热键（如 `Option + Space` / `Alt + Space`）一键快速唤起/隐藏工作台小窗。
  - 支持通过热键调出极简「快捷 Workflow 执行面板」。

### Phase 4：平滑自更新与打包发布流水线 (5.0.0 Release)
- [ ] **后台静默更新 (Auto Update Pipeline)**：
  - 结合 `useDesktopBridge` 中的 `applyDesktopUpdate(manifest)`，实现后台静默下载增量/全量更新包，校验签名后提示用户「重启以应用新版本」。
- [ ] **多平台构建流水线 (CI/CD Packaging)**：
  - 配置 GitHub Actions 构建产物：macOS (`.dmg` / `.app`)、Windows (`.exe` 安装包 / `.msi`)、Linux (`.AppImage` / `.deb`)。

## 🔐 安全与环境护栏
1. **网络通信隔离**：桌面壳 WebView 严格限制在 `127.0.0.1` 本地回环端口通信，禁用外部不信任 URL 加载。
2. **IPC 白名单**：只开放指定的 Bridge API 函数，防止恶意脚本通过 IPC 执行任意 Shell 命令。
3. **数据完整性**：升级/更新应用前强制触发一次 SQLite 完整性检查与本地快照备份（对接现有 `/api/backup`）。
