# oh-my-co-work 3.5 · 熔炉简易对话皮

| 属性 | 内容 |
|------|------|
| 目标版本 | `3.5` |
| 状态 | **已落地** |
| 日期 | 2026-08-19 |
| 前置 | 本机 Grok TUI（3.3）；同一条 `grok` 进程 |

给熔炉一张 **铺满页面的对话皮**，不是小对话框。缩小后回到工作台三栏。终端仍是同一进程。

## 1. 两档尺寸（对话皮与 TUI 共用）

| 档 | 作用 |
| --- | --- |
| **铺满页面** | 默认。整页就是熔炉干活面（挂到 `body`，不困在中栏）。 |
| **缩小到三栏** | 熔炉仍占中栏，左右会话/流程可见。 |
| **返回群聊** | 关掉这层皮；Grok 进程还在，可从终端卡再进来。 |
| **全屏** | 可选；交给浏览器铺显示器。 |

教程弹层（未装 / 未登录）仍可以是对话框。一旦能跑 Grok，进的是铺满干活面。

## 2. 两张皮，一条进程

| 皮 | 做什么 |
| --- | --- |
| **画面**（默认） | 去颜色的 Grok 终端画面**尾部**（不是多轮气泡）+ 底部输入。Enter 写入同一 PTY；拼音选词 Enter 不发送。 |
| **终端** | 原来的 Grok TUI。菜单、快捷键走这里。 |

设置 → Grok Build →「开熔炉默认」：铺满对话 / 铺满终端。工具栏随时切换。

不新开成员类型，不第二份 SQLite，不调另一套 Chat API，不解析屏幕当 Adapter。

## 3. 不做

- 小 Modal 当主界面  
- 独立桌面窗 / 托盘（4.x）  
- 模型切换、插件市场、自研 tool calling  

## 4. 验收

- 点精灵开熔炉：默认铺满，不是居中小窗。  
- 「缩小」能看见左会话 / 右流程。  
- 对话与终端来回切，进程不断。  
- 归档仍回收该 PTY。  
- 关掉熔炉后普通脚本成员仍走原来的终端工作区。
