# oh-my-co-work 3.5 · 熔炉简易对话皮

| 属性 | 内容 |
|------|------|
| 目标版本 | `3.5` |
| 状态 | **已落地** |
| 日期 | 2026-08-19 |
| 前置 | 本机 Grok TUI（3.3）；同一条 `grok` 进程 |
| 后续 | [crucible-3.7.md](./crucible-3.7.md) |

给熔炉两张皮：**GUI**（去颜色 + 输入框）和 **TUI**（原终端），不是小对话框。缩小后回到工作台三栏。同一条 grok 进程。

## 1. 两档尺寸（GUI 与 TUI 共用）

| 档 | 作用 |
| --- | --- |
| **铺满页面** | 默认。整页就是熔炉干活面（挂到 `body`，不困在中栏）。 |
| **缩小到三栏** | 熔炉仍占中栏，左右会话/流程可见。 |
| **返回群聊** | 关掉这层皮；Grok 进程还在，可从终端卡再进来。 |
| **全屏** | 可选；交给浏览器铺显示器。 |

教程弹层（未装 / 未登录）仍可以是对话框。一旦能跑 Grok，进的是铺满干活面。

## 2. 两张皮，一条进程

| 皮 | 做什么 |
| --- | --- |
| **GUI**（默认） | **可读正文**（屏幕还原后再去掉 TUI 框线/底栏）+ 底部输入。菜单和快捷键请切 TUI。可把文件落到 `inbox/`，发送时把相对路径写成一行写入同一 PTY。 |
| **TUI** | 原来的 Grok 终端。菜单、快捷键走这里。 |

设置 → Grok Build →「开熔炉默认」：铺满 GUI / 铺满 TUI。工具栏随时切换。

不新开成员类型，不第二份 SQLite，不调另一套 Chat API，不解析屏幕当 Adapter。原理：[crucible-grok-client.md](./crucible-grok-client.md)。

## 3. 不做

- 小 Modal 当主界面  
- 独立桌面窗 / 托盘（4.x）  
- 模型切换、插件市场、自研 tool calling  

## 4. 验收

- 点精灵开熔炉：默认铺满，不是居中小窗。  
- 「缩小」能看见左会话 / 右流程。  
- GUI 与 TUI 来回切，进程不断。  
- 归档仍回收该 PTY。  
- 关掉熔炉后普通脚本成员仍走原来的终端工作区。
