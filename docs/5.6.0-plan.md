# 5.6.0 需求文档 — 5.x 收尾加固与三平台桌面补全

> 状态：**规划中** · 生成日期：2026-10-23
> 本文档汇总 5.0.0～5.5.0 计划文档中**仍未完成或括号残留**的条目，作为 5.6.0 需求的单一事实源。
> 完成一项即在本文件打勾，并回写源 plan 对应条目（维护约定见「六」）。

---

## 一、目标与范围

**一句话**：把 5.x 系列欠下的收尾做完——三平台桌面打包、超大文件拆分收尾、无障碍补齐、通知实机验收，同时吸收各版 bracket 残留的高价值项。

**5.6.0 要解决的问题**：

1. macOS / Linux 用户仍拿不到正式桌面安装包（DESK-07）。
2. `useSessionDetail` 仍 ~614 行，热更新与维护成本高（FE-01 / ENG-04）。
3. Workbench 表格、对话框键盘可达性不达标（UX-03）。
4. 通知功能缺实机验收与长跑验证（NTF-T3 / T4）。
5. 各版收尾时留下的「待补 / 待实机验证」bracket 项无人认领、逐版累积。

**不做什么**：见「七、暂不做」。

## 三、非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 启动 < 3s；列表滚动不掉帧；SSE 合并写入 |
| 兼容 | Windows 10/11；macOS 12+（Intel / Apple Silicon）；Ubuntu 22.04+ / Fedora 38+ |
| 安全 | 无 XSS / IPC 越权 / 日志泄露；依赖漏洞扫描 0 high |
| 可测 | 新增功能均有 E2E 或单测；性能有基线数据 |
| 可维护 | 纯逻辑单文件 ≤ 300 行；组件职责单一 |

## 五、实施建议顺序

1. **ENG-04 / FE-01** — `useSessionDetail` 收尾拆分（纯重构、风险低，先做）
2. **UX-03** — Workbench 表格 / 对话框 aria 与键盘路径
3. **SEC-01 / 02 / 03** — 安全加固收尾（专项测试 + IPC 校验 + 日志脱敏）
4. **DESK-07** — macOS / Linux 打包与签名（依赖证书，尽早启动）
5. **CP-03** 与 **CP-02 / 06 / 09** 实机验证
6. **NTF-T3 / NTF-T4** — 实机 QA 与 8 小时长跑（依赖 4 的安装包）
7. 其余 P1 / P2 按剩余时间填充
