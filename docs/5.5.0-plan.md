  Windows runtime + desktop 已有（见 `packages/README`）；**macOS / Linux Electron 安装包与代码签名**待补；pack-release 三平台 CI 绿。

- [ ] **FE-01 P1 超大单文件拆分**  
  `useSessionDetail` 已拆至 ~614 行（filter/reset/init 模块等）；**剩余逻辑继续下沉**，直至单文件与热更新目标达标。

  HTTP/CLI 已走 `createBackupAsync` / `restoreBackupUnlockedAsync`；备份目录列表、暂存清理与还原文件树检查已改为异步并有回归测试，生产入口不再调用同步 create/restore。**integrity_check / wal_checkpoint 已下放 `node:worker_threads`（`sqliteIntegrityWorker.js`，worker 不可用时回退进程内同步 pragma）**；db.js 启动期 integrity_check 保持同步（一次性启动路径，可接受）。声明「生产热路径全异步」成立。

  skip-link、focus-visible、App/Workbench/命令面板/SessionRail 已部分完成；设置子页 Members/Groups/Shortcuts/RestoreCenter/About 的 aria-label、表格操作按钮、抽屉/对话框焦点与快捷键表格开关可访问名已补齐（Element Plus el-drawer/ElMessageBox 自带 focus trap 与焦点归还）；**Workbench 表格、对话框**键盘路径与 aria 待补。
