# 通知实机检查清单（5.4.0 NTF-T3）

各平台一份，跑通后在 PR 或发布说明中勾选日期与版本。自动化覆盖见 `shared/notificationPolicy.js` 单测与 `electron/test/notifier.test.mjs`。

## Windows 10 / 11

- [ ] 系统设置未禁用 oh-my-co-work 通知；专注助手开启时行为符合预期（应用内收件箱仍记录）
- [ ] 窗口隐藏/最小化到托盘后，人工闸门 **3 秒内** 弹出系统通知
- [ ] 点击通知：主窗口恢复、路由到对应会话/闸门
- [ ] 托盘 tooltip 待办数与退出前确认（有待处理项时）
- [ ] 任务栏 `flashFrame`（失焦时）
- [ ] 声音：`需要你`/`出错了` 有提示音；`完成了` 默认静默；设置关闭声音后无声
- [ ] 设置页「发送测试通知」可用

## macOS（Intel 或 Apple Silicon）

- [ ] 首次通知权限引导；未授权时设置页有说明
- [ ] 已签名包与未签名包行为差异已记录（若适用）
- [ ] Dock 角标与通知点击深链
- [ ] 声音与勿扰时段

## Linux（GNOME / KDE）

- [ ] `libnotify`/DBus 可用时通知弹出；缺失时应用内提示与设置说明
- [ ] 点击深链、托盘菜单

## 通用

- [ ] 顶栏铃铛收件箱：未读/已读、点击条目深链
- [ ] 同会话前台查看时不弹系统通知（应用内高亮）
- [ ] 勿扰时段内不弹窗、仍写入收件箱
- [ ] 关闭到托盘首次提示含「通知仍会送达」

## 备注

- **NTF-T4** 长跑（8h）需单独排期；本文不替代长跑记录。
- 未覆盖项请在 `docs/5.4.0-plan.md` 保持 `[ ]` 直至有证据。
