# 下个版本规划（5.0.0）：性能优化与交互优化

> 现状判断：功能面已经铺得很广，但**还没有达到「能用」级别**——卡、慢、输入不跟手、关键路径有坑。
> 5.0.0 不再加新能力，只做两件事：**性能优化**、**交互优化**。验收以「日常连续使用不卡、不丢输入、不迷路」为准。

> 具体到文件的问题清单与优先级见 [optimization-backlog.md](./optimization-backlog.md)（持续维护）。

## 一、重点：内置 CLI / 熔炉精灵

### 1. 内置终端（cursor-cli / grok 等）

| 问题 | 方向 |
| --- | --- |
| 粘贴后无法再输入（`window.confirm` 抢走焦点，Electron 下常见） | 4.9.x 已改为非阻塞确认并恢复焦点；5.0 补回归测试，并评估默认改为 bracketed paste、不再弹确认 |
| 输出量大时界面卡顿 | PTY 输出合并分帧写入（rAF 批量 `xterm.write`）、背压与丢帧策略；scrollback 上限与内存监控 |
| 切换会话/标签后重放慢 | replay 增量快照、只重放可视区附近；隐藏标签暂停渲染 |
| resize 抖动、列数异常 | fit 防抖、仅在可见且稳定后下发 PTY resize |
| 焦点管理混乱（弹窗、抽屉、精灵点击后丢焦点） | 统一「终端焦点守卫」：任何浮层关闭后恢复到上一个活动终端 |
| 中文输入法（IME）、复制粘贴快捷键不一致 | 梳理 Ctrl/Cmd+C/V、右键菜单、选区复制；IME 组合态测试 |
| 进程退出后的恢复路径不清晰 | 一键重启同配置会话、保留上次输出 |

### 2. 熔炉精灵

- 体积：展开态已缩小约三分之一；继续做**自动收起**（空闲 N 秒、全屏终端时）与可拖到边缘吸附
- 全局可用：设置页也显示（4.9.x 已加）；终端全屏/文档中心页的显示策略统一成一个可配置项
- 不挡内容：默认落点避开右栏操作区；与气泡、流程卡片做碰撞回避
- 性能：精灵动画使用 CSS 雪碧图 + `will-change`，页面不可见/减少动态偏好时停帧；避免 `setTimeout` 链常驻
- 交互：气泡文案与当前状态联动（等待确认、运行中、失败），点击行为一致（单击气泡、双击开熔炉）

## 二、性能优化

1. **启动**：首屏体积分析（Element Plus 按需引入、xterm 懒加载）、服务端冷启动与迁移耗时打点，目标冷启动到可交互 < 3s
2. **列表与详情**：会话列表虚拟滚动；`useSessionDetail` / 文档中心列表增量刷新，替换全量轮询
3. **实时通道**：SSE/轮询合并，统一心跳；后台标签降频
4. **渲染**：文档中心 Markdown 渲染结果缓存、大文档分段渲染；右栏切换不重复请求
5. **服务端**：SQLite 热点查询加索引、批量写入合并事务；大文件（备份导入/导出）流式处理，避免整包读入内存
6. **度量**：加入轻量性能面板（FPS 近似、PTY 吞吐、API 耗时 P95），作为回归基线

## 三、交互优化

1. **缩放与布局**：顶栏缩放控件（已加）持久化；窄窗口下三栏自适应折叠规则
2. **数据管理**：一键导入 / 一键导出对称（已改）；导入前预览备份元信息（版本、会话数、大小）与失败回滚提示
3. **文档中心**：阅读体验对齐飞书文档（正文大、标签小、留白舒展，已落地第一版）；补目录大纲、锚点跳转、阅读宽度切换
4. **确认类操作**：统一使用非阻塞对话框，禁用原生 `confirm/alert`
5. **反馈**：长任务统一进度与可取消；错误提示给出下一步动作
6. **键盘**：常用操作快捷键清单与冲突检测；终端与输入框之间的焦点切换规则

## 四、验收标准（Definition of Done）

- 连续使用 30 分钟（含 3 个并发终端会话、大量输出）无明显卡顿，主线程长任务 < 100ms
- 粘贴、IME、全屏切换、弹窗关闭后，终端**始终可继续输入**
- 精灵不遮挡任一页面的主要操作区
- 所有性能项有基线数据与回归脚本（`scripts/selftest-*`）
- 新增/修改交互均有对应的 web/electron 测试

## 五、不做

- 新增 Agent 类型、新工作流节点类型、新设置大项
- 云端同步、多用户
