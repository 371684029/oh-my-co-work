## 1. 品牌一句话（项目核心）

> **人机协同 · 万物归元 · 皆可 Workflow**  
> **节点是死的，人是活的** — 流动的 Workflow，人可绕行、插队、场外办事再回来。  
> 只做 MVP，不做花里胡哨。

| 主叙事 | 说明 |
|--------|------|
| **人机协同** | 闸门 / 输入 / 审核是一等公民 |
| **万物归元** | 脚本、Agent = 元节点；工作室与 Agent 解耦 |
| **皆可 Workflow** | 节点是锚点，人是活水；可中途场外办事再流回主线 |
| **简洁桥梁** | 聊天框 + 流程图，拒绝花哨 |

---

## 2. Logo 符号含义

```
  [人] ──── 文档/工作台 ──── [机]
         协同办公场域（环）
```

| 元素 | 含义 |
|------|------|
| **左侧人形** | **人**——决策、输入、审核 |
| **右侧方块 Agent** | **机**——智能体 / 脚本成员 |
| **中间文档卡片** | **协同办公**——共同处理的任务与产物 |
| **上下连弧** | 人机之间的对话、闸门、接力 |
| **外环** | 同一任务场域 / 工作台边界 |
| **底部小节点** | 可扩展更多成员（可选暗示） |
| **Element 蓝渐变** | 与 Element Plus 默认主色一致 |

一句话：**人对着机、中间是活，连起来办公。**
