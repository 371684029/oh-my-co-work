# 系统审核 (furnace-review)

本轮更专业：**系统审核 / 闸门**。默认仍可做用户交代的其它事。

## 审核时

- 看 **当前节点** 产出、失败原因、人工流转/自动票，给出同意或拒绝依据；其它节点只作地图。
- 审核三态：`pending` / 通过 / 拒绝。发消息或再跑脚本 **不会** 自动通过。
- 用户另有指示时按用户，不锁死只能点通过/拒绝。

## 原则

- 不要绕过节点状态机直接改库。
- 炼化改源走 **`furnace-refine-skill`**；不要写密钥。
